# Anggie Huang - Data Analyst Portfolio

A clean, modern portfolio website showcasing analytics projects, skills, and experience.

## 📋 Features

- **Responsive Design** - Works perfectly on desktop, tablet, and mobile
- **Smooth Animations** - Fade-in effects and smooth scrolling
- **Modern UI** - Clean, minimalist design with blue accent color
- **Interactive Elements** - Hover effects, scroll animations, number counters
- **SEO Optimized** - Proper semantic HTML and meta tags
- **Fast Loading** - Pure HTML/CSS/JavaScript (no frameworks)

## 🚀 Quick Start

1. Clone this repository:
```bash
git clone https://github.com/yourusername/portfolio.git
cd portfolio
```

2. Open `index.html` in your browser to view locally

3. Deploy to GitHub Pages:
   - Push your code to GitHub
   - Go to your repository settings
   - Under "Pages", select "Deploy from a branch"
   - Choose your main branch
   - Your site will be live at `https://yourusername.github.io/portfolio/`

## 🎨 Customization

### Colors
Edit the CSS variables in `styles.css` (top of the file):
```css
:root {
    --primary-color: #1a1a1a;
    --accent-color: #2563eb;
    /* ... more colors ... */
}
```

### Content
Edit the HTML sections in `index.html` to update:
- Hero section (title, subtitle)
- About section (bio, stats)
- Projects (add/remove project cards)
- Skills (update technical skills)
- Experience (update work history)
- Contact (update links)

## 📱 Responsive Breakpoints

- **Desktop**: 1200px+
- **Tablet**: 768px - 1199px
- **Mobile**: Below 768px
