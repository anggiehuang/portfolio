Work Example

Measurement Framework Dashboard Building

Content Performance Framework

Designed a scalable measurement framework consolidating 6 data sources into a single benchmarked score across 1,000+ content pages. The scoring logic is built around percentile analysis of the client's own historical data — making the benchmark contextually meaningful and directly tied to their editorial strategy.

Problem

Marketing teams published articles regularly but had no mechanism to evaluate performance. They were producing content without any feedback loop — unable to distinguish between what was genuinely resonating and what was underperforming.

Impact & Result

  • Self-serve dashboard enabling non-technical stakeholders to independently assess any piece of content against the full portfolio — immediately seeing absolute performance and relative ranking
  • Enabled data-driven content strategy decisions: which articles to promote, update, or deprioritise
  • Framework embedded into the client's ongoing content workflow — genuinely adopted rather than a one-off deliverable

BigQuery SQL Statistical Analysis

Anomaly Detection System

Built an automated anomaly detection system in BigQuery to catch data integrity issues across a global client's GA4 properties. Detection logic is based on historical traffic patterns rather than fixed thresholds — using standard deviation and 95% confidence intervals to flag anomalies.

Problem

Bot traffic had distorted GA4 data irreversibly, creating reporting accuracy issues. With 20+ regional websites and data informing marketing strategy organisation-wide, manual weekly QA checks weren't scalable — they'd miss issues between checks and consume disproportionate analyst time.

Impact & Result

  • Eliminated manual weekly QA checks across regional sites — freeing analyst time and ensuring consistent monitoring
  • Caught a server-side tracking break before the client noticed, enabling proactive notification and minimising reporting impact
  • System now runs as a live early warning mechanism, automatically flagging data quality issues before they reach stakeholder reporting
